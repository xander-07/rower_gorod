Кнопка выше — дополнительный предохранитель браузера. Движение всё равно возможно только если ROS запущен с enable_motion:=true.

Для чистой карты: прямая → остановка 0.5–1 с → медленный поворот на месте → остановка 0.5–1 с → прямая. Дуги намеренно отключены.

Клавиши: W/↑ вперёд, S/↓ назад, A/← поворот влево, D/→ вправо, Space стоп.
