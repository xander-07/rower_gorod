# rower_gorod

Проект автономного шестиколёсного робота для хакатона «Движение по городу» Кубка РТК.

## Аппаратная платформа

- Робот: Waveshare UGV02, 6WD.
- Бортовой компьютер: Raspberry Pi 5, 8 GB.
- Лидар: LDROBOT STL-19P.
- Базовый код производителя Raspberry Pi: `waveshareteam/ugv_rpi`.
- Нижний контроллер платформы: ESP32; связь с Raspberry Pi по GPIO UART JSON-командами.

## Что должен делать робот

Робот должен полностью автономно двигаться по городскому полигону, соблюдать дорожную разметку и установленные знаки, выполнить остановки в зонах посадки пассажиров не менее чем на 2 секунды и завершить маршрут остановкой перед знаком «Парковка».

Полигон имеет размер 4 × 4 м и состоит из сетки 5 × 5 ячеек по 800 мм. Внутри расположены четыре здания. Старт задаётся организаторами в одной из угловых ячеек вместе с начальным направлением движения.

Используемые знаки:

- движение прямо;
- движение налево;
- движение направо;
- поворот налево запрещён;
- поворот направо запрещён;
- остановка;
- парковка;
- опасный объект / ограждение.

Организаторы разрешают использовать заранее построенную карту полигона.

## План программной архитектуры

Проект строится вокруг ROS 2 и делится на независимые узлы:

1. `ugv_base_bridge` — управление UGV02 и публикация состояния базы.
2. `ldlidar` — публикация `/scan` с LDROBOT STL-19P.
3. `robot_description` — TF и геометрия робота/лидара/камеры.
4. `localization_navigation` — SLAM/локализация и Nav2.
5. `sign_detector` — распознавание дорожных знаков камерой.
6. `mission_manager` — логика задания: остановки, выбор разрешённого направления и финиш на парковке.
7. `bringup` — единый запуск всей системы.

## Важное правило репозитория

Все файлы, которые необходимы для работы проекта на Raspberry Pi 5 — ROS 2 пакеты, launch-файлы, параметры, модели, скрипты установки и диагностики — хранятся в этом репозитории.
